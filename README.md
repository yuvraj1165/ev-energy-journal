## About this project

This journal records real-world EV charging and home-energy results over time. The public repository contains only published articles, charts, aggregate results and other information intended for public sharing.

Sensitive source material such as electricity bills, account information and raw personal data is kept separately in the private `ev-energy-journal-private` repository.
