## About this project

This journal records real-world EV charging and home-energy results over time. The public repository contains only the published article, charts, aggregate figures and other information intended for public sharing.

Each month a new Octopus half-hourly export and Andersen charger export are run through a tracker that recomputes everything from the underlying data and regenerates the figures, tables, bar charts and the negative-price calendar heatmap. The article is then updated with the fresh numbers.

Sensitive source material such as electricity bills, account information and raw personal data is kept separately in the private `ev-energy-journal-private` repository.
